# Options trading from zero

**Start with [your first tiny lesson](START_HERE.md).** This course teaches U.S. stock and ETF options to someone with no trading experience, in **10–15 minute study sessions**. You need a notebook and a basic calculator. Coding, a brokerage account and paid data are optional later tools.

The [beginner course](beginner/README.md) contains **64 lessons in eight modules**, with worked examples, fresh questions, folded answers, checkpoints, reviews and a final practical assessment. Learn one concept, try one problem, and stop for the day. Repeat a lesson whenever you need to.

## Your course app

The full application is in [course-app](course-app/README.md). It provides a lesson reader, server-graded quizzes, saved notes and progress, scheduled recall reviews, a practice payoff chart, a resource library and a downloadable learning record. Progress starts empty and changes only when you do the work. Your private hosted app uses ChatGPT sign-in.

The frontend uses React and TypeScript. The backend uses Vinext route handlers, Cloudflare Workers, D1 and Drizzle migrations. See the application README for running it locally and the verification record for the checks actually completed.

## After the beginner course

The existing [104-week advanced curriculum](COURSE.md), [four teaching volumes](LESSONS_01_FOUNDATIONS.md), [research lab](RESEARCH_LAB.md), [operations casebook](OPERATIONAL_CASEBOOK.md) and [Python labs](labs/README.md) remain available for deeper study. They are optional extensions, with their own prerequisites and projects.

Completion demonstrates learning and practice; it does not establish a profitable trading strategy or authorize live trading. Choosing to keep studying, use options only for understanding, or avoid options is a valid result.

## Verification

The [verification report](VERIFICATION_REPORT.md) records the **November 14, 2026** review, corrections, mathematical checks, application checks and limits. The [source library](SOURCES.md) links to SEC, OCC/OIC, FINRA, exchange and other primary materials. Examples use invented prices unless explicitly identified as observations. A course cannot establish that it is the best in the world or guarantee profits; this course aims for clear teaching, accurate mechanics and demonstrable understanding.
