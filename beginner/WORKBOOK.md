# Your small daily workbook

[Beginner course](README.md) · [Review plan](REVIEW_PLAN.md) · [Full library](../README.md)

Copy the block needed today into your notebook or a new file. You do not need to complete every template at once. Keep first attempts alongside corrections; an error is useful learning evidence. The existing [learning record](../MY_LEARNING_RECORD.md) remains preserved; these blocks do not assert any prior skills or assessment passes.

## 1. Daily lesson card · use from Lesson 01

```text
Study date and lesson number:
Today's one idea, in my own words:
My first try-it answer and calculation (before viewing the key):
What I got right:
Correction, if needed, and why:
One sentence explaining the answer aloud:
Next small step or changed-number retry:
Recall dates: next study day / after 3 study days / after 7 study days
```

Do not give yourself a pass for copying the explanation. A better check is a new number or a short explanation without looking.

## 2. Recall and checkpoint card

```text
Lesson/module reviewed:
Question I answered without notes:
My saved answer:
Check against key: correct / partly correct / not yet
If wrong, mistaken idea (units, sign, cash, shares, timing, or definition):
Corrected reasoning:
Fresh retry question and scheduled study day:
Fresh answer and result:
Funding/expiry/assignment/order-status errors all corrected? yes/no
```

For a checkpoint that takes more than 15 minutes, save the work and continue next session. Correct cash/share and operational errors before advancing to material that relies on them.

## 3. Quote notebook · use after learning quote fields

Observation is enough. No order or brokerage deposit is required. If collecting actual quotes, use a legally available source and identify delayed data as delayed.

```text
Observation date/time and time zone:
Source and source quote time; known data delay:
Underlying symbol and observed underlying price/time:
Exact option series: call/put, strike, expiration date, adjustment/root:
Premium multiplier and deliverable; specification or memo source:
Bid / ask; displayed sizes if available:
Last trade and its timestamp, if provided:
Spread per quote unit and dollars per one contract:
Known event or corporate action; facts not checked yet:
What this observation shows:
What it cannot prove about execution or future profit:
```

If a field is unavailable, write **unknown**. A missing timestamp is not permission to call a quote current.

## 4. Fictional paper ticket · use after the operations module

```text
SIMULATION ONLY — no live order submitted
Decision date/time and time zone:
Exercise or observation source (invented case / dated quote):
Exact underlying and option terms; quantity for every leg:
Action: buy/sell to open/close; multiplier and deliverable:
Why this position? What would reject the idea?
Compare with: cash / shares / simpler position / no trade
Exercise style and settlement; actual expiry and last trading time:
Events and broker rules known / unknown:
Observed bid/ask and quote age; order limit and validity:
Fee assumptions; adverse-fill assumption; nonfill handling:
Cash paid/received; modeled loss; share/funding/assignment case:
Hypothetical practice limit; does one whole contract fit?
Exit and expiry plan, including deadlines needing confirmation:
Decision: simulate / wait / no trade; reason:
```

For a fictional case, use only the fills expressly supplied. For a shadow observation, label hypothetical fills as assumptions. You cannot infer a passive limit fill just because the market later moved favorably.

## 5. Cash and position ledger

Copy rows as events occur. Use positive shares for owned stock and negative shares for short stock. Use positive option quantity for a long option and negative for an open short. Cash is not the same as equity.

| Time/event | Confirmed order status | Cash change | Cash balance | Shares | Each option quantity | Mark/source | Account equity |
| --- | --- | ---: | ---: | ---: | --- | --- | ---: |
| Start | No open orders | 0 |  | 0 | None |  |  |
| Entry | Filled / partial / unfilled / unknown |  |  |  |  |  |  |
| Later event |  |  |  |  |  |  |  |
| Close or settlement |  |  |  |  |  |  |  |

In a simple case, **equity = cash + share market value + long-option value − short-option liability**. Multiply shares by the stated stock mark; multiply option quotes by quantity and their actual multiplier. A market mark estimates value; a fill determines an executed cash flow. Track external deposits/withdrawals separately if they exist.

## 6. Assignment and expiration rehearsal

```text
Exact option and relevant product rules:
Position before event: cash / shares / options / pending orders:
Event: exercise / assignment / expiry / cash settlement / unknown status
Shares received or delivered (with sign):
Strike cash payment or receipt:
Earlier premium and fees, kept separate:
Which option disappeared? Which still exists?
Funding/margin and dividend consequences in this case:
Resulting positions and equity under the stated marks:
Any later stock-price exposure or open order?
Broker deadline/procedure that a real case would require:
What evidence would confirm that the account is resolved?
```

A spread's long option remains a separate position unless the case or actual confirmed instruction says otherwise. A submitted cancellation is not a confirmed cancellation. For fuller practice use the [operational casebook](../OPERATIONAL_CASEBOOK.md).

## 7. A complete no-trade entry

```text
Date and observation:
Idea considered:
Reason to abstain (unclear term / large contract / wide spread / event / no signal / other):
Known facts supporting that reason:
What remains unknown:
Useful next learning step:
No trade submitted; no trade P&L claimed:
```

You do not need to invent a trade to fill the workbook. A clear abstention is a recorded decision.

## 8. Five-minute weekly review

```text
Lessons actually completed and still needing a retry:
One explanation I can now give without notes:
One repeated error and how I will change my practice:
Any simulated fill, cost, or position assumption I overstated:
Next study session and one older lesson to recall:
```

Keep the weekly review about learning and accounting. A profitable fictional result does not erase a process mistake.
